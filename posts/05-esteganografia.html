Dá para esconder uma imagem dentro de outra sem ninguém perceber?

Um pixel RGB tem números suficientes para mostrar uma cor. E, às vezes, sobra espaço para carregar uma segunda informação sem mudar quase nada do que vemos.

1 de outubro de 2026·7 min de leitura
  • esteganografia
  • RGB
  • LSB
  • bits

A ideia da esteganografia parece coisa de filme: esconder uma mensagem de forma que ninguém perceba que existe mensagem alguma. Em imagem digital, dá para fazer uma versão simples desse truque mexendo justamente nos bits que menos alteram a cor de um pixel.

Um canal de cor é só um número

Num RGB comum de 8 bits por canal, cada valor vai de 0 a 255. Em binário, isso significa oito posições. A posição da esquerda vale muito; a da direita vale só 1.

10101100→10101101

Os dois números são 172 e 173. Visualmente, mudar um canal de 172 para 173 costuma ser praticamente imperceptível. Esse último dígito é o least significant bit, ou LSB.

Se eu usar o LSB de muitos canais para guardar uma sequência de zeros e uns, consigo esconder dados enquanto a imagem continua parecendo a mesma.

O segredo está no que o olho não liga muito

Suponha que uma mensagem comece com os bits 1 0 1. Eu poderia pegar três canais consecutivos e forçar seus últimos bits para esses valores. Cada canal muda no máximo uma unidade.

A interação é uma visualização do conceito, não a decodificação de uma imagem externa. O princípio usado no texto é o LSB.

Imagem dentro de imagem

Em vez de texto, também dá para armazenar os bits mais importantes de uma segunda imagem nos bits menos importantes da primeira. Quando a imagem “secreta” é reconstruída, ela perde qualidade porque recebeu poucos bits por canal, mas pode continuar reconhecível.

A capacidade depende de quantos bits você aceita alterar. Usar um LSB de cada canal RGB oferece três bits de carga por pixel. Usar mais bits aumenta espaço, mas também aumenta a chance de o disfarce ficar visível.

Esteganografia não é criptografia

As duas podem aparecer juntas, mas resolvem problemas diferentes. Criptografia transforma o conteúdo para que ele não seja entendido sem a chave. Esteganografia tenta esconder a própria existência da comunicação.

CRCriptografia

“Você pode ver a mensagem, mas não consegue entender.”

STEsteganografia

“Você nem percebe que existe uma mensagem aqui.”

+As duas juntas

O conteúdo pode ser cifrado antes de ser escondido.

O formato do arquivo importa

O método LSB simples combina melhor com formatos sem perda, como PNG. Se você esconder bits e depois salvar como JPEG, a compressão pode alterar justamente os valores que carregavam a mensagem. O JPEG do post anterior seria um péssimo cúmplice.

Também existe a esteganálise, que procura padrões estatísticos capazes de denunciar conteúdo escondido. Então “imperceptível a olho nu” não significa “impossível de detectar”.

O que eu tirei disso

O que mais gostei nesse tema foi perceber que um pixel pode ter duas leituras. Para nós ele é uma cor. Para um programa ele é uma sequência de bits — e a diferença entre essas duas visões abre espaço para esconder informação.

A imagem não mudou de função; quem mudou foi a forma de ler os mesmos números.
