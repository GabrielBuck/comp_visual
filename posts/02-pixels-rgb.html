Post 02 · representação de imagens

Como um computador enxerga uma imagem?

Para nós, uma fotografia parece contínua. Para o computador, ela pode ser descrita como uma grade de números. Entender essa mudança de perspectiva é uma das portas de entrada para Computação Visual.

25 de agosto de 2026·7 min de leitura

Uma imagem como matriz

Uma imagem digital raster pode ser pensada como uma grade bidimensional. Cada posição dessa grade é um pixel, abreviação de picture element. Em vez de guardar “céu”, “rosto” ou “árvore”, o arquivo guarda valores que descrevem a aparência de cada ponto.

Em uma imagem em tons de cinza, por exemplo, cada pixel pode ser representado por um único valor de intensidade. Em um caso comum de 8 bits, esse valor vai de 0 a 255: 0 representa preto, 255 representa branco e os valores intermediários correspondem a diferentes tons de cinza.

imagem = [
  [  0,  32,  64,  96],
  [ 32,  64,  96, 128],
  [ 64,  96, 128, 192],
  [ 96, 128, 192, 255]
]

Essa forma de pensar é poderosa: se a imagem é composta por números, operações visuais podem ser formuladas como operações matemáticas. Aumentar brilho, desfocar, detectar bordas ou comparar regiões passa a ser, em algum nível, transformar esses valores.

E a cor?

Uma forma muito comum de representar cor em telas é o modelo RGB: vermelho (red), verde (green) e azul (blue). Em vez de um valor, cada pixel passa a ter três componentes.

R+G+B→cor

Se cada canal usar 8 bits, ele pode assumir 256 valores. Com três canais, isso produz 256 × 256 × 256 = 16.777.216 combinações possíveis de RGB.

Experimente: misturando RGB

Mova os controles abaixo. A cor resultante é construída diretamente pelos três valores selecionados. O ponto é perceber que aquilo que enxergamos como uma única cor pode ser armazenado como uma pequena tupla de números.

rgb(94, 92, 230)#5e5ce6

Resolução não é “qualidade” sozinha

A resolução espacial descreve quantos pixels existem na imagem. Uma imagem de 1920 × 1080 possui 2.073.600 pixels. Mais pixels permitem representar mais detalhe espacial, mas isso não garante, sozinho, que a imagem seja melhor: lente, sensor, compressão, ruído, iluminação e processamento também influenciam o resultado.

Uma distinção útil

Resolução espacial fala sobre quantos pontos amostramos no espaço. Profundidade de bits fala sobre quantos valores conseguimos representar em cada amostra.

Profundidade de cor e quantização

Se diminuirmos a quantidade de valores permitidos em cada canal, cores próximas passam a ser representadas pelo mesmo valor. Esse processo está ligado à quantização. Em situações extremas, surgem faixas visíveis em regiões que deveriam ter transições suaves — um efeito conhecido como banding.

Isso mostra uma ideia fundamental da representação digital: o mundo visual é contínuo em muitos aspectos, mas o computador precisa amostrá-lo e descrevê-lo com uma quantidade finita de dados.

Por que isso importa para Computação Visual?

Porque quase tudo o que vem depois depende dessa representação. Um filtro percorre pixels. Um detector de bordas procura variações nos valores. Um algoritmo de segmentação tenta separar regiões. Um modelo de visão computacional recebe tensores derivados desses dados. E um sistema gráfico, no final de seu pipeline, precisa decidir quais valores serão escritos nos pixels da tela.
